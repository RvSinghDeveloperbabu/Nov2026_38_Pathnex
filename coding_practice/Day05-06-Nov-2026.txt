## Jenkinsfile - With Git Integration and Testing

pipeline {
  agent any
  stages {
    stage('Clone Repository'){
      steps{
        git 'https://github.com/RvSinghDeveloperbabu/Nov2026_Ravi_Pathnex.git'
      }
    }
    stage('build') {
      steps {
        echo 'Building project from Git repository'
      }
    }
    stage('Test') {
      steps {
        echo 'Running the unit test cases'
      }
    }
    stage('deploy') {
      steps {
        echo 'Deploying Application'
      }
    }
  }
}

## Ansible - Create User and Set Permission

- name: Create a new User
  hosts: all
  become: yes
  tasks:
    - name: Create User
      state: present
      shell: /bin/bash
    - name: Set permission for the User
      file:
        path: /home/pathnex
        owner: pathnex
        group: pathnex
        mode: '0755'
